You need to have Python, Jupyter notebook, NumPy and pandas installed and set up for this.
You will need to an Nvidia graphics card with CUDA cores, Nvidia CUDA Toolkit and CuPy installed to run `gpu_recog.ipynb`. If you don't have all this, run `cpu_recog.ipynb` instead.
